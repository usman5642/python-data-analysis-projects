# Data Analysis with Python Projects

A collection of 17 exploratory data analysis (EDA) projects built while developing my Python data-analysis skills. Each project takes a real public dataset, cleans it, explores it, and answers a set of practical questions using pandas, with visualisations in matplotlib and seaborn.

These are foundational practice projects. They show the everyday craft of data analysis: loading messy data, handling missing values, filtering and grouping, and turning a raw table into clear answers and charts.

## Tools

Python, pandas, NumPy, matplotlib, seaborn, Jupyter Notebook.

## Skills practised across the set

- Data cleaning and preparation (missing values, type conversion, string handling)
- Filtering, grouping, aggregation, and sorting with pandas
- Descriptive statistics and value distributions
- Correlation and relationship analysis
- Data visualisation (bar, line, scatter, histogram, heatmap, count plots)
- Translating a dataset into clear, question-driven insights
